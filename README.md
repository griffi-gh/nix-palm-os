# Palm OS Tools/SDK as Nix packages

work in progress

Includes the following packages:

- Collection of Palm OS SDKs (https://github.com/jichu4n/palm-os-sdk)
- PilRC (https://github.com/jichu4n/pilrc), with 3.3.0 patches by Dmitry Grinberg
- PRC-Tools (https://github.com/jichu4n/prc-tools-remix) (does not build from source yet)
- Retro68-palm (untested) - modern gcc for Palm OS development, with patches by Dmitry Grinberg
  - (patches from https://www.reddit.com/r/Palm/comments/p81m58/announce_new_gcc_or_palmos_again/)
