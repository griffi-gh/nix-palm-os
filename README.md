# Palm OS Tools/SDK as Nix packages

Includes the following packages:

- Collection of [Palm OS SDKs](https://github.com/jichu4n/palm-os-sdk)
- [PilRC](https://github.com/jichu4n/pilrc), in two flavors:
  - 3.2.0 (last official release)
  - 3.3.0-unofficial with patches by Dmitry Grinberg
- [PRC-Tools](https://github.com/jichu4n/prc-tools-remix) (does not build from source yet)
- Retro68-palm - modern gcc for Palm OS development, with [patches by Dmitry Grinberg](https://www.reddit.com/r/Palm/comments/p81m58/announce_new_gcc_or_palmos_again/)

(work in progress)

For example, see: https://github.com/griffi-gh/nix-palm-os-hello-world
